💡 처리 내용: 거래명세서 전체 건을 대상으로, 수납일이 있으면 수납일자/수납금액을 채우고 미수납금액=0, 없으면 미수납금액=Total금액으로 채웁니다 → 월말업체(파일③) / 기존업체(수납 안 된 채 기준일이 속한 분기보다 이전 발행분이 있는 업체) / 일반업체로 자동 분류 → 연체개월수·업체구분에 따라 색상 적용 → 수납데이터(파일②)에 같은 업체의 최근 입금내역이 있으면(미수납 건에 한해) 비고란에 "확인필요"로 표시(자동 제외는 하지 않음) → 업체명순 정렬 → 요약 파일 생성. 전체 폰트는 굴림체 8pt로 원본 템플릿에 맞췄습니다. "합계" 컬럼은 같은 업체가 연속된 행들의 미수납금액을 합산해 마지막 행에 표시합니다. 1행에는 제목(20pt 굴림, 직접 수정 가능), 5행부터 헤더·데이터가 시작되고 D~H열(공급가액~DC금액)은 숨김 처리됩니다.

모든 처리는 브라우저 안에서만 이루어지고 파일은 어디에도 전송되지 않습니다.
